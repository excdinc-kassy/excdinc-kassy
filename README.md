## 📖 Currently exploring

- **Supply-chain integrity for extensions** — signing, verification and safe updates for plugins and themes
- **A strict Content Security Policy** — moving the whole admin and front end to a CSP with no inline scripts and no `unsafe-eval`
- **Sandboxing plugins** — how far a CMS can limit what an installed extension is able to touch
- **AI without giving up security** — letting AI agents work with a CMS inside its existing permission model
